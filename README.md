# 🎬 Clone Netflix

Projeto inspirado na interface da Netflix, desenvolvido com foco em design moderno, responsividade e interatividade utilizando JavaScript.

---

## 🚀 Sobre o projeto

Este projeto recria a experiência de navegação da Netflix com uma interface personalizada e funcionalidades interativas.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## ✨ Funcionalidades

- Seleção de perfis
- Gerenciamento de perfis
- Modo escuro e modo claro
- Catálogo de filmes
- Exibição de trailers
- Interface responsiva

---

## 📱 Responsividade

- Layout adaptado para diferentes tamanhos de tela

---

## 📌 Objetivo

Projeto desenvolvido para evolução prática em front-end e construção de portfólio.
